À propos d'aDaube Acrobait

Remplacer le texte : cliquez sur un morceau de texte dans votre PDF. L'éditeur le recouvre visuellement puis ajoute votre version par-dessus. Le texte original reste techniquement présent dans le fichier : ce n'est pas un outil de caviardage sécurisé.

Polices : le catalogue inclut des noms de polices Microsoft, Apple et libres. Une police doit être disponible sur votre appareil pour être affichée correctement. Pour garantir son rendu dans le PDF exporté, importez un fichier TTF/OTF que vous avez le droit d'utiliser.

Limites : conservation visuelle approximative des textes remplacés, pas de modification native des objets PDF, ni d'OCR, ni de signature numérique. Les documents et les polices restent dans la session du navigateur. Les bibliothèques PDF.js, pdf-lib et les icônes sont chargées depuis des CDN au premier usage.
